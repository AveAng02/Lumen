# Lumen
Building a ray tracer based on the book Ray Tracing in One Weekend Peter Shirley edited by Steve Hollasch and Trevor David Black.

![First Sphere](https://github.com/AveAng02/Lumen/blob/jpeg-format-support/output/output_normal.png)

## Build

* mkdir build
* cd build
* cmake ../
* cmake --build .
* ./lumen
